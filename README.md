🔥 Multimodal Image Analysis Agent










📌 Project Overview

This project showcases how Gemini’s multimodal capabilities can analyze real-world images and produce clear, structured outputs.
The model interprets the scene, identifies people and roles, extracts visible text, and generates formatted insights.

We used a real example image of students presenting their engineering project during a college exhibition to demonstrate practical use-case value.

Built by Shelke Ashwin and Isha Thombare.

🎯 Key Features

Image understanding with context awareness

Extracts visible text (if any)

Generates natural-language summaries

Produces structured JSON output

Gives insights + recommendations

Simple and clean HTML interface

API-ready for integration
